# Tutorials

Complete analyses, each taken from real experimental work rather than invented
for the page. Every one runs against spectra that ship with the package, so you
can work through it before loading any data of your own, then swap in your
files at the end.

Each page is also a notebook: use the download button at the top right to get
the `.ipynb` and edit it directly.
