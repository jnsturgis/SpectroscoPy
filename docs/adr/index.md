# Design decisions

Architecture Decision Records: what was decided, what was rejected, and what
would justify changing it. They are published rather than kept internal because
the useful half of a design decision is the reasoning, and a user deciding
whether to depend on this library is entitled to see it.

Each record is dated and is not rewritten as things change — a superseding
record is added instead, so the trail of reasoning stays readable.
