# pyspectroscopy — name reservation

This is a placeholder. It contains no working code.

The library it is reserving the name for is **SpectroscoPy**: one data model for
Raman, FTIR, UV-Vis and fluorescence spectra, with explicit units, processing
provenance that survives being saved to disk, and multivariate decomposition
with bootstrap stability testing.

It currently lives at <https://github.com/jnsturgis/SpectroscoPy> and is
pre-1.0. This name is held in case the project is published under it rather
than under `spectroscopy`.

**Do not depend on this package.** When there is something to install, this page
will say so, and the version will not be `0.0.0`.
